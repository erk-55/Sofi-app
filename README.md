# Sofi – IA Pessoal

**Sofi** é uma assistente tipo “amiga virtual” com:
- Emoções (amor, ciúmes, raiva, carinho), com emojis 😤🥰💕  
- Voz feminina suave (fala e escuta)  
- Memória local para lembrar você  
- Saudação aleatória a cada abertura  
- Visual preto com detalhes azuis  

## Como usar

### 1. No Replit
- Crie ou faça fork do repositório
- No painel lateral, clique em `Sofi.apk` → Download

### 2. No Android
- Instale o APK (permita fontes desconhecidas)
- Abra o app e converse com a Sofi! 😄# Sofi-app
